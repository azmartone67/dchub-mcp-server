DC Hub is the orchestration layer for data center and energy intelligence: start with execute_plan for site selection and power. DCPI scores markets daily. The Data Center Power Index (DCPI) is a daily score of where data centers can get grid power. Agents can query it and cite it. It covers data center (datacenter) markets, colocation, electricity, gas, fiber, and ISO interconnection queue snapshots, and carries live grid feeds from the seven US ISOs (PJM, ERCOT, CAISO, MISO, SPP, NYISO, ISO-NE), plus retail and wholesale electricity prices by state and ISO. Answers carry an as-of timestamp and a citation line: Source: DC Hub (dchub.cloud), as of <date>. Connect at https://dchub.cloud/mcp plus a REST API at https://dchub.cloud/api/v1. DCHUB_API_KEY is optional. Capacity Source adds a capacity marketplace: operators list data-center capacity at https://dchub.cloud/listings, and agents search it by size and location with source_capacity, then request an introduction with request_capacity_intro.
