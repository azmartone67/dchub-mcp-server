The two guarantees

Provenance on every response. Each result carries citation — source, url, license (CC-BY-4.0), and retrieved_at. Every number traces back to a definitive source.

Honest unknowns. The site-diligence tools return each factor with coverage: validated | unavailable. When data isn't sourced, the tool returns unavailable — never a fabricated number. For institutional diligence, an explicit "unknown" beats invented precision.

Verify it yourself

# live tool count (expect 70)
curl -s https://dchub.cloud/.well-known/mcp.json | python3 -c "import sys,json;print(json.load(sys.stdin)['tools_count'])"

# full tool schemas
curl -s -X POST https://dchub.cloud/mcp -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
