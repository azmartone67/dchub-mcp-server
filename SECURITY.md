# Security Policy

To report a vulnerability in dchub-mcp-server, use the contact details in our
machine-readable policy:

**https://dchub.cloud/.well-known/security.txt**

Please do not open a public issue for a suspected vulnerability. Include the
affected version, reproduction steps and impact. We aim to acknowledge reports
promptly and will credit reporters who want credit.

Only the latest published release receives security fixes.
