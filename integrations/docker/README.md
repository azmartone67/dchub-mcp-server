# DC Hub in Docker's MCP Toolkit

DC Hub is a remote MCP server at `https://dchub.cloud/mcp` (streamable HTTP). It has no image to pull and needs no key: the free tier answers without credentials.

## Add it to Docker Desktop

```bash
docker mcp catalog import https://raw.githubusercontent.com/azmartone67/dchub-mcp-server/main/integrations/docker/catalog.yaml
docker mcp server enable dchub
```

DC Hub then appears in the MCP Toolkit beside Docker's own catalog, and every client connected to the Docker MCP gateway can use it. `docker mcp catalog update` re-fetches the catalog when the tool list changes.

To remove it, run `docker mcp server disable dchub` and `docker mcp catalog rm dchub`.

These are the catalog commands of the Docker MCP gateway. If you turned on the newer profiles feature, which turns catalog management off, connect your client to `https://dchub.cloud/mcp` directly instead.

## What the catalog holds

[`catalog.yaml`](catalog.yaml) has one remote server entry: the endpoint, the transport, and the tool list. It is generated by `scripts/build-docker-catalog.mjs` from `toolspec.json` and `canonical/listing-copy.json`, and `daily-manifest-sync` regenerates it when either one changes.

## Docker's official catalog

The entry for Docker's own registry is [docker/mcp-registry pull request 4644](https://github.com/docker/mcp-registry/pull/4644), open since 2026-08-06 and waiting for review. The catalog above works without it.
